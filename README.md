# 🏛️ TopoLogos: The Engine of Structural Existentialism

> "Intelligence is not about finding the optimal path instantly, but about pruning the inefficient paths immediately."

**TopoLogos** is a Neuro-Symbolic Knowledge Graph engine built with **Modern C++ (C++23)**. Unlike traditional RAG systems that rely on probabilistic generation, TopoLogos **"compiles"** knowledge into rigorous binary logic, enforcing structural constraints while allowing existential refusal.

## 🧐 Philosophy: Structural Existentialism

This project explores the intersection of **Computer Science** and **Philosophy**.

1.  **Structure (The Constraints):** The system enforces physical (Entropy) and structural (Fragility) laws. High-entropy claims (e.g., "Get Rich Quick") are mathematically rejected.
2.  **Existentialism (The Refusal):** Users define their own truth by **"pruning"** unwanted paths. It is an **Inverted Skill Tree**—growth is achieved not by adding skills, but by eliminating inefficiencies.
3.  **Organic Change:** Individual refusals aggregate to update the system's topology, simulating social evolution.

## 🚀 Key Features

* **Triangulation Verification:** Cross-validates claims using Physics (Entropy), Psychology (Mental Cost), and Structure (Fragility).
* **Zero-Cost Abstraction:** Compiles certain truths (`Strong Link`) into direct function calls for nanosecond latency.
* **C++23 `std::expected`:** Encapsulates logical nuances and uncertainties within strict type safety.
* **Anti-Scam Logic:** A built-in "Bullshit Detector" that filters out logical fallacies and unsustainable systems.

## 🛠️ Usage

### 1. Define Reality (`.topo`)
Write your structural constraints in the TopoLogos DSL.
```cpp
Community Physics {
    Concept Effort;
    Concept Result;
    // Law: Zero input cannot produce high output.
    Effort -> Result; 
}

2. Mine & Compile
Extract facts from the web and compile them into a C++ header.
python3 miner.py "Coding"
cmake --build build --target TopoLogos
./build/TopoLogos life.topo

3. Verify Truth
Run the engine to verify claims against the structural laws.
./build/GraphApp "Coding" "Rich"
